- Helm scored 0 in both arms because the feature tests did not compile: required `MergeStrategies` and `MergeKeys` methods were missing from `Install` and `Upgrade`.
- FastAPI implicit HEAD scored 0 in both arms; the stock verifier showed a HEAD request returning 405.
